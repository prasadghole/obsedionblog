# obsedionblog vault

Markdown second-brain, replacing the old Emacs org-mode + Hugo workflow.

## Folder layout
- `posts/` — published blog posts (source of truth for the site)
- `drafts/` — work in progress, not yet published
- `clippings/` — saved web pages (via Obsidian Web Clipper)
- `attachments/` — images/screenshots referenced by notes
- `templates/` — note templates (e.g. daily capture, blog post)
